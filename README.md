# Personal portfolio site

A one-page personal portfolio and résumé website.

## Customize it

1. Your resume details and contact information are already added. Update the LinkedIn/GitHub links in `index.html` if you would like to include them.
2. Place your actual résumé PDF in this folder as `resume.pdf` so the download button works.
3. Open `index.html` in a browser to preview it.

The site is plain HTML, CSS, and JavaScript—no installation needed.
